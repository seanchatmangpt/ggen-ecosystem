# Standing import prior art

This note extends the existing seven-day frontier intake without creating another authority stack.

Selected mature donors are OpenID AuthZEN Authorization API 1.0 Final, SPIFFE workload identity, W3C PROV-O, A2A Protocol v1.0, and FIBO. Canonical ownership remains respectively AshA2A for authorization-decision evidence and A2A carriage, Affidavit for workload identity and provenance, and GraphLaw for finance semantics.

Import does not imply authority. Protocol conformance, identity, provenance, transport success, policy decisions, and ontology classification remain evidence until the receiving canonical owner admits the exact subject.

Preserved negative knowledge: AuthZEN decisions are not actuation; SPIFFE identity is not consequence authority; PROV derivation is not semantic equivalence; A2A is a communication protocol rather than an agent runtime or tool protocol; FIBO semantics do not establish settlement finality or execution authority.

Falsifier: this intake fails if any donor can enter strict composition without pinned identity/version and admitted standing, or if donor technical standing is promoted into runtime authority.
