# Compounding reference stack

The RFC reference stack is a projection graph, not a collection of competing frameworks.

GraphLaw owns semantic law-state and the Knowledge-Hook candidate contract. The ecosystem projects that admitted source into consumers. Ash/Ashler projects application structure; AshR2RML observes it; SA2A carries powerless consequence intent; Affidavit carries trust/evidence; Reactor realizes admitted operations; CASTLE owns product-level consequential constitution and BRCE; receipts/OCEL feed Beam4PM; XaaS composes runtime placement.

The FIBO payment case is intentionally a semantic delta rather than a new payments framework. Adding `fibo:PaymentExecution` must reuse exact-subject identity, source binding, replay identity, the SA2A thin waist, the existing trust plane, CASTLE BRCE, receipts and process feedback.

A build fails the compounding claim if it needs a second semantic engine, authority system, consequence protocol, receipt truth, or replay subsystem merely because FIBO was added.
