# Consumed-subject negative court

This court qualifies the standing-import verifier's exact-subject boundary without granting runtime authority.

## Required observations

Given the marketplace absorption pack declared by `contracts/standing-imports/v26.9.30.json`:

1. An exact clean checkout at the declared commit must yield `standing=ALIVE`, the same `observed_marketplace_sha`, and `observed_pack_clean=true`.
2. A checkout at any adjacent commit must yield `REFUSED` containing `MARKETPLACE_SUBJECT_SUBSTITUTION`.
3. A checkout at the declared commit with any tracked or untracked mutation under the consumed pack path must yield `REFUSED` containing `MARKETPLACE_SUBJECT_DIRTY`.
4. An input whose Git subject cannot be observed must yield `REFUSED` containing `MARKETPLACE_SUBJECT_UNOBSERVABLE`.

Passing this court establishes provenance binding only. It does not imply semantic equivalence, runtime authority, or DO authority.

## Reverse-Chesterton constraint

Do not replace Git commit identity with a content-only digest. Commit identity preserves repository history and provenance; a deterministic pack digest is admissible only as a secondary byte-identity witness. Adjacency is not equivalence.
