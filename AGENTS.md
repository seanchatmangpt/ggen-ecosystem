# ggen-ecosystem operating doctrine

## Authority
This repository is the canonical composition root of the ggen ecosystem. Its ontology and admission sources outrank generated projections.

## Manufacture
- Prefer existing `ggen-marketplace` packs.
- Do not create a new pack here.
- Project-specific observations and admission data belong here; reusable executable knowledge belongs in `ggen-marketplace`.
- Generated outputs are never editing surfaces.
- Tera is the template language where a pack requires templating.

## DfCM
Preserve -> Fence -> Calculus -> Exclusions -> Falsifier -> Extension -> Operationalization.

Maximize lawful reversible option capital before irreversible selection. A failed edge is topology, not graph failure. Bound possibilities by ontology, capability, authority, cost, evidence, and explicit exclusions.

## Execution
`SELECT`, `CONSTRUCT`, and `DO` are distinct. Only a receipted broker may perform `DO`.
Hooks emit intents only. CI is evidence transport, not authority.

## Standing vocabulary
Use only `UNKNOWN`, `PARTIAL_ALIVE`, `ALIVE`, `BLOCKED`, `BUILD_BROKEN`, `UNSUPPORTED`, and typed `REFUSED`.
Inspection is not execution. Workflow definition is not workflow success. Named receipt files are not receipts unless their verifier accepts them.

## Repository workflow
- Resolve `main` to an exact SHA before work.
- Use a purpose branch.
- Never silently move the base.
- Verify the exact branch head.
- Merge only when explicitly requested and only against the inspected head.
- Record transport failures and missing execution surfaces as typed evidence rather than smoothing them over.

## GitHub composition
Repositories remain independently versioned. Do not turn this repository into a source monorepo.
Use `ecosystem.lock.toml` for exact external identities and `profiles/*.ttl` for semantic closure.

## Public ontology
Prefer PROV-O, DCAT, DCTERMS, SKOS, SHACL, ODRL, FOAF, QUDT, SOSA/SSN, SPDX, and OCEL-compatible concepts where they fit. Local terms exist only for ecosystem-specific relations not supplied by public ontology.

## Generated directories
`generated/`, `consumer/`, and `.ggen-v2/` may be produced by ggen. Do not hand-edit them.
